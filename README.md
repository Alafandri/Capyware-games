# CAPYWARE GAMES

---

### What is Capyware games?
Capyware games is a game where you have to give your all to make the capybara happy! It's a simple WarioWare game with fast paced minigames.

### What does this game feature?
This game features hand 5 drawn pixel art style levels featuring fun fast paced minigames each different from eachother.

### How to play:
1. You can play the game on your broswer on https://alafandri.itch.io/capyware-games site.
2. If you want to download the game then Instructions are below:

### Run Instructions(for people who want to download the game)
1. Go to the [releases](https://github.com/Alafandri/Capyware-games/releases/tag/Release1.1) tab in this repository
2. Find the latest release
3. Download and unzip the game
4. Run the game and enjoy!

> **Note:** If you get windows defender warning then just press "More info" and you should get the button to play the game. Don't worry it's not a virus!

---

### Controls:
- Jump: `Space`
- Move: `Left arrow key` / `Right arrow key`
- Interact: `Left mouse click`
